cgmlst-dists-py

Pairwise cgMLST Hamming distance matrix from chewBBACA allele-call tables, in Python. Byte-identical to the original cgmlst-dists by default, with GrapeTree-compatible missing-data handlers, exact deduplication and optional GPU.

GitHub Bioconda Docker (ghcr.io) cgmlst-dists-rs

Install

Bioconda

conda install -c bioconda \
  cgmlst-dists-py

Recommended. --gpu works with an NVIDIA driver on the host.

Docker

docker pull ghcr.io/genpat-it/cgmlst-dists-py

CPU-only image; Dockerfile.gpu builds a GPU one.

From source

git clone https://github.com/genpat-it/cgmlst-dists-py
cd cgmlst-dists-py
pip install -r requirements.txt

pip install -r requirements-gpu.txt for --gpu.

Usage

cgmlst-dists.py -i chewbbaca.tab -o distances.tsv
cgmlst-dists.py -i chewbbaca.tab -o distances.tsv -y 0     # GrapeTree pair_delete
cgmlst-dists.py -i chewbbaca.tab -o distances.tsv --dedup  # clonal data, exact
cgmlst-dists.py -i chewbbaca.tab --stdout -m lower-tri

Distance = number of loci where the two alleles differ and both are present (default -y 3, the original cgmlst-dists semantics). A leading INF- is stripped; chewBBACA classes (LNF, PLOT3, ASM, …), - and empty cells are missing.

Missing-data handlers

-ynamebehaviour
0pair_deleteignore missing per pair, rescale to all loci (GrapeTree default)
1complete_deletedrop loci not called in every sample
2as_allelemissing is an allele: missing vs called is a difference
3absolute_distanceignore missing per pair, absolute count — default

Full option list in the README.

chewBBACA hashed profiles

Hashed profiles store CRC32 hashes as allele ids, up to 4 294 967 295. Alleles are read as 64-bit integers. In releases ≤ 0.1.7, in a locus that also held text (*N novel alleles, chewBBACA classes), every hash above 231 was turned into the same number, so different alleles compared equal.

Listeria, Pasteur cgMLST (1748 loci), 2099 genomes ≤ 0.1.7fixed
ERR10109288 vs ERR101092898571196
ERR10109289 vs ERR101092912535

The fix is on main and ships in the next release. On these data the output is md5-identical to tseemann cgmlst-dists 0.6.0 and to cgmlst-dists-rs.

Benchmarks

20 000 samples × 3 000 loci, synthetic (generator below), full matrix on an 80-core x86-64 box. All three produce md5-identical output. Best clean run.

implementationruntime
tseemann cgmlst-dists 0.6.0 (C, -j 80)97 s
cgmlst-dists-py (CPU, 80 cores)93 s
cgmlst-dists-py --dedup, clonal data (2 000 distinct profiles)64 s
cgmlst-dists-rs (Rust, 80 cores)5.8 s

Python is on par with the multithreaded C tool; for raw speed use cgmlst-dists-rs. cgmlst-dists-py adds the GrapeTree handlers, --dedup and GPU.

Reproduce

No large datasets are shipped; generate them with the script in the repository:

python benchmark/cgmlst-data-generator.py --samples 20000 --loci 3000 --missing 5 --output bench20k.tsv
python benchmark/cgmlst-data-generator.py --samples 1000 --loci 1500 --hashed --output hashed.tsv
time python cgmlst-dists.py -i bench20k.tsv -o py.tsv
